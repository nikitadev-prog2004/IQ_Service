# Lumina — учебный сервис IQ-тестов

Короткий тест мышления с подпиской на подробный отчёт. Оплата имитируется: банк не участвует, в базе сохраняются ответы, балл и статус подписки.

## Запуск

Локально нужен Node.js 22 и PostgreSQL, например Neon. Секреты в репозиторий не кладутся: образец без пароля лежит в `.env.example`.

```bash
npm install
npm run migrate
npm start
```

`npm start` локально вызывает `server.listen`. На Vercel слушатель порта не запускается: платформа берёт `export default` из `server.js` и передаёт ему исходный путь, включая `/api/session`.

Откройте http://localhost:3000

На оплате используйте карту `4242 4242 4242 4242`, срок `12/30` и любые три цифры CVC. Настоящую карту вводить не нужно: номер проверяется по алгоритму Луна и в базу пишутся только последние 4 цифры.

База: PostgreSQL, таблицы `sessions`, `answers`, `results` и `payments`. Файл `data/lumina.db` больше не используется.

## Деплой на Vercel

В проект Vercel добавьте переменную `DATABASE_URL` для Production и Preview. Берите pooled-строку Neon: в хосте есть `-pooler`. Обычная строка тоже подойдёт, подготовленные выражения отключены.

Команды с машины, где уже стоит Vercel CLI и выполнен `vercel link`:

```bash
npm install
npm run migrate
vercel --prod
```

`npm run migrate` применяет `migrations/001_init.sql` один раз и записывает это в `schema_migrations`. Повторный запуск ничего не меняет. Та же миграция выполняется при первом обращении к API, под блокировкой `pg_advisory_xact_lock`, чтобы параллельные экземпляры не создали таблицы дважды.

## Воронка

1. **Главная** — обещание, пример вопроса, цена до старта.
2. **Тест** — 12 вопросов, ответы пишутся на сервер по одному.
3. **Подсчёт** — короткая честная пауза, без «эксперта на линии».
4. **Paywall** — широкая оценка без точного балла.
5. **Оплата** — учебный чек на 149 ₽ и согласие на продление 399 ₽ в месяц.
6. **Результат** — балл, кривая, четыре навыка, разбор, отмена продления.

Точный балл отдаёт только `GET /api/session/:id/result`, и только после оплаты.

## Что взято у существующих сервисов

Смотрел три типа продуктов.

- **MyIQ, Cerebrum, IQ Test Brain.** Бесплатные вопросы, затем экран «результат готов». Точное число скрыто, рядом формулировка вроде «выше среднего». Дальше мелкий платёж около $1, который в условиях превращается в подписку $20–40 каждые 2–4 недели. Часто есть таймер, формулировка «проверка карты» и путаница в кнопках отказа. Конверсия высокая, доверие и возвраты платежей плохие.
- **Brainable.** Тот же каркас: тест бесплатный, отчёт за пробный период, затем автопродление (в публичных условиях встречались и $1.99 за 7 дней с переходом на более крупный период, и ежемесячные планы около $20–40). Поверх отчёта продаются тренажёры.
- **IQTest.com.** Общий балл бесплатно и сразу. Подробный профиль по шкалам — разовая покупка около $15–20, без подписки. Понятнее, слабее запирает результат.

У Lumina оставлен продающий порядок экранов: человек сначала вкладывает 8 минут, потом видит, что отчёт уже посчитан, и только затем платит. Монетизация подписочная, как в брифе: **149 ₽ за 7 дней, затем 399 ₽ в месяц**, отмена на странице результата, доступ к уже открытому отчёту сохраняется.

Цена стоит на главной и на paywall обычным текстом. Качественная оценка («заметно выше среднего») не заменяется выдуманным числом и не сопровождается фальшивым счётчиком пользователей. Нормы названы модельными: центр 100, шаг 15, кривая нормальная, живой выборки у MVP нет.

## Стек

`node:http`: локально через `npm start`, на Vercel через `export default` сервера из `server.js`. База — клиент `postgres` и `DATABASE_URL`. Интерфейс — одна страница, сначала мобильная ширина. Сессия в браузере — только UUID. Ответы, результат и учебная оплата лежат в PostgreSQL и привязаны к этому UUID.

## API

| Метод | Путь | Зачем |
| --- | --- | --- |
| GET | `/api/health` | Проверка базы, без секретов |
| POST | `/api/session` | Новая сессия |
| GET | `/api/questions` | Вопросы без ключа |
| POST | `/api/session/:id/answer` | Один ответ |
| POST | `/api/session/:id/complete` | Подсчёт, наружу только широкая оценка |
| POST | `/api/session/:id/checkout` | Учебная оплата |
| POST | `/api/session/:id/cancel` | Отмена продления |
| GET | `/api/session/:id/result` | Полный отчёт, если оплачен |

## Ограничения

Шкала иллюстративная, не клинический IQ. Продление не списывается само: в базе хранится дата и статус, платёжного планировщика нет. Очереди и почты нет. Полный номер карты и CVC в базу не пишутся.
